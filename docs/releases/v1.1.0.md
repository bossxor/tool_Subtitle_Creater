# Subtitle Tool v1.1.0

일본어 음성 인식·번역 선택지를 추가하고, 원문 훼손과 자막 시간 오류를 수정했습니다. 기존 자막은 검사·비교한 뒤 선택한 줄만 백업 후 업데이트할 수 있습니다.

## 변경 사항

- 일본어 회화 전용 인식 모델 선택 추가. 기존 large-v3 기본값은 유지합니다.
- 번역 품질에서 TranslateGemma 27B 정밀 모드 선택 가능. 기본 12B는 유지하며, 정밀 모드는 시스템 메모리 32GB 이상 권장·16.5GB 추가 다운로드·처리 속도 감소가 있습니다.
- 용어집 원어 표기를 음성 인식에도 참고합니다.
- 원어에 맞는 음성 트랙을 선택하고 코멘터리는 후순위로 처리합니다.
- 금액·번호·정상 반복 대사 보존, 긴 침묵을 넘는 자막 합침과 과도한 대사 삭제 수정.
- 말투 판별, 영문·안내문·약어만 남는 출력 검사, 잘린 번역 응답 처리 개선.
- 기존 자막 생성 이력 확인, 번역 후보 비교, 선택 적용, 원본 백업, 번역만 다시·음성 인식부터 다시 처리 지원.
- 라이트·다크 화면과 작업 결과 상태 표시 개선.

## 설치와 업데이트

1. `Subtitle_Tool-win64.zip`을 새 폴더에 풀고 `Subtitle_Tool/Subtitle_Tool.exe`를 실행하세요.
2. Windows 10/11 64비트, NVIDIA GPU·드라이버, PATH에 등록된 ffmpeg가 필요합니다. GPU 메모리는 8GB 이상을 권장합니다.
3. 모델·llama.cpp 실행 엔진은 압축 파일에 포함하지 않으며 첫 실행 시 필요한 항목을 다운로드합니다. 기존 설치의 `models`·`tools`를 재사용할 수 있습니다.
4. 기존 자막과 캐시는 업데이트 전에 보관하세요. 음성 트랙·인식·번역 검증 기준이 바뀌어 이전 단계 캐시를 다시 계산할 수 있습니다.

첨부된 `.sha256` 파일로 ZIP의 SHA-256을 확인할 수 있습니다.

## 검증과 한계

- 관련 자동 테스트 81개 통과. 로컬 실행 파일 재빌드, 포함 코드·설정의 소스 일치, 기존 사용자 캐시 759개 보존 확인.
- 일본어 인식 모델과 번역 모델을 고정 입력으로 비교했으며 자세한 근거는 [품질 측정 기록](https://github.com/bossxor/tool_Subtitle_Creater/blob/main/docs/superpowers/plans/2026-11-08-quality-measurements.md)에 있습니다.
- 정밀 모델도 오역·딱딱한 말투가 남습니다. 새 일본어/27B 조합의 전체 영상 검증은 미완료입니다. 깨끗한 PC의 최초 모델 다운로드 전체 과정도 아직 검증하지 못했습니다.
